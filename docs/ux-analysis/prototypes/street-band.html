Piso luminoso junto al campus

Calle de Pedro II el Católico Universidad

The map marks the street, not the door. Travel times are a best–worst range over the whole street, merged by the server into one response. The exact point never reaches the browser.

Reading the range: the server routes from both street ends and the true door, takes min–max, and rounds outward to whole minutes. The true time is inside the range by construction.
